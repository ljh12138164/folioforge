## 交互与真实结果边界

- 原图在左、输出在右；先使用原文件 URL 与真实编码结果 URL，两层共享尺寸、缩放与平移。输出缩小后按原图坐标放大对齐，普通模式的 100% 按原图像素显示。
- 可拖分界线或画面；缩放按钮、100%、适应及 Ctrl / ⌘ + 滚轮提供 5%–800% 的缩放范围。适应不自动放大小图。滑块有名称、值和焦点样式，方向键每次 1%，Shift 每次 10%，Home / End 到两端。
- pointercancel、lostpointercapture 与窗口失焦释放当前手势；画面平移受边界约束。新输出以 URL 为 key 重建比较器，重新转换及切换结果后恢复初始视图。
- 原生全屏只在浏览器支持时显示，失败以内联提示解释；预览失败有错误提示。体积与尺寸来自实际文件和输出数据，比例可表达减少或增大。
- 浏览器无法原生解码任意一侧时，两侧共同切换到引擎缩略预览，明确说明 100% 按预览像素显示、不代表原图细节。这里的“100%”不能当作真实原图像素检查。
- 修改设置后需重新转换；处理期间保留上次结果并说明其状态，不宣称实时质量预览。

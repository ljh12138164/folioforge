# OCR 与压缩实现交付

2026-10-24。用户在早期方案验证后要求“全部实现”，现已把剩余两个 PDF 工具接入 `/pdf/`；沿用现有界面、本地处理与 Web 验收。研究历史仍见 [方案与独立实验](PDF-OCR-COMPRESSION-VALIDATION.md)，不以历史“尚未实现”描述当前产品。

## OCR

入口 `/pdf/?tool=ocr`，支持简体中文、英文及中英混合，150/200 DPI，TXT 和可搜索 PDF。按当前排列及选页范围顺序执行，每批最多 20 页，页面渲染限长边 3000px / 400 万像素，结果限 100 MiB / 500 万字符。手机建议每批 1–3 页，此建议不是实机内存基准。

默认直接读取已有非空文字层；生成 PDF 时复制这些页并保留当前旋转，不叠加第二层 OCR。可显式选择重新识别全部页面。识别结果按页展示、字面搜索、打开原页核对，下载完整 TXT；可搜索 PDF 可预览输出首页。

需要 OCR 的页由 PDF.js 按可见区域/旋转渲染，Tesseract 识别并生成图片加不可见文字的 PDF，再等比映射到原可见物理尺寸。因而文字可以搜索和复制，但原有矢量、链接、注释和标签不保留。空结果不是文档损坏；中文小字、表格、竖排、倾斜和低对比输入没有准确率保证。现阶段不提供校对编辑器或正文编辑功能。

Tesseract.js / core 均精确锁定 7.0.0，主线程直接管理该固定版本的 Worker 消息协议，确保初始化、加载模型及识别时均可终止并拒绝未完成任务；协议升级需重跑真实 OCR 验收。单 Worker 顺序处理，Canvas 逐页释放，替换输出时释放预览文档；取消或失败不产生半成品下载。

## 压缩

入口 `/pdf/?tool=compress`：

- **重存优化**：pdf-lib 对象流重存，不降低图像分辨率或把文字转图。输入为完整且未重排/旋转的单一来源时，体积基准是来源原始字节；选页、多来源、重排/旋转时，基准是当前范围按当前顺序导出的 PDF。不能承诺已紧凑的文件继续缩小。
- **扫描件降采样**：PDF.js 整页白底渲染，JPEG 画质 40–95%，96/150/200 DPI，同样受像素上限约束。需要用户先明确勾选内容损失。可选文字（包括 OCR）、矢量、链接、注释和标签会丢失；小字、印章、二维码可能变模糊。

显示处理前/后实际 PDF 字节和节省比例，不使用图片编码大小充当 PDF 大小。输出不小于基准时，提供基准文件并明确“未缩小”。输出成功不替换工作区原页，原文件和已有编辑历史保留；支持结果首页预览和下载。压缩比取决于输入文件，合成噪声夹具的节省不能用于宣传真实文档的典型压缩率。

## 同源、离线与许可

构建脚本 `scripts/prepare-ocr-assets.mjs` 复制 Worker 和普通/SIMD/relaxed-SIMD 三种 LSTM core 分支；只启用 OEM=1，不分发未使用的 Legacy 分支。fast 模型固定到官方提交 `87416418657359cb625c412a48b6e1d6d41c29bd`，首次构建下载并按已记录 SHA-256 核验；后续本地命中时也检查哈希。部署时 `/pdf-assets/ocr/v7/` 包含中英模型、引擎与模型许可、资源清单。Tesseract.js 的 postinstall 仅为募捐提示，按仓库配置不运行。

引擎和模型仅从当前站点加载；生产 Service Worker 将其与既有 PDF 资产统一缓存。等待“离线资源已就绪”后可断网冷重载，并首次执行 OCR。语言模型通过应用资源缓存读取，不把用户图片写进 IndexedDB/Cache Storage。清除站点数据或浏览器回收缓存后需重新联网；新增 OCR 目录本机实测 13 个文件、27,005,063 字节（约 25.75 MiB，磁盘文件大小，不是压缩传输量），首次缓存会比此前下载更多资源。

上游依据：[Tesseract.js v7 API](https://github.com/naptha/tesseract.js/blob/v7.0.0/docs/api.md)、[v7 PDF 输出源码](https://github.com/naptha/tesseract.js/blob/v7.0.0/src/worker-script/utils/dump.js)、[固定 fast 数据](https://github.com/tesseract-ocr/tessdata_fast/tree/87416418657359cb625c412a48b6e1d6d41c29bd)。资源目录保留对应 Apache-2.0 许可；现有 PDF.js / pdf-lib 许可维持不变。

## 验收证据

`test/pdf-heavy.spec.mjs` 在真实 Edge 浏览器执行：断网冷重载后首次中英 OCR，TXT 精确包含合成样本文字；可搜索 PDF 中文回读、英文文字坐标和原可见尺寸；已有文字页不重复、选页、20 页限制、初始化取消；模型请求失败时不生成下载、恢复请求后重试成功；矢量重存文字保留、扫描 PDF 实际缩小、变大时原字节回退；输出首页实际渲染。测试的中文内容为代码生成的清晰大字，不代表真实文档准确率评测。
